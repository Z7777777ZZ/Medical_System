# 互联网医疗系统 - 用户服务系统

这是一个互联网医疗系统的用户服务子系统，主要实现以下功能：

## 功能模块

### 1. 新手引导漫游系统
- 系统使用指南
- 交互式引导漫游
- 视频教程
- 常见问题解答

### 2. 用户反馈系统
- 系统反馈
- 就诊体验反馈
- 康复情况反馈
- 弹窗式反馈收集

### 3. 消息推送系统
- 预约日期通知
- 复检日期通知
- 系统消息推送
- 通过邮箱和手机号推送
- 通知设置管理

### 4. 用户行为时间轴
- 收集用户在系统内的重要操作
- 可视化时间轴显示
- 支持筛选和搜索
- 提供数据分析图表

### 5. 健康日报助手
- 每日健康贴士
- 个人健康状态展示
- 健康资讯推送
- 健康相关广告展示

## 技术栈

### 前端
- Vue 3 (Composition API)
- Element Plus UI库
- Axios (HTTP客户端)
- Vue Router (路由管理)
- Chart.js (图表绘制)
- Driver.js (引导漫游)

### 后端
- Flask (Python Web框架)
- MySQL (数据库)
- REST API架构

## 测试说明

本系统支持以下测试类型：

### 1. 边界测试
可以测试以下边界情况：
- 表单输入验证边界（最大/最小字符数，有效/无效输入）
- 用户行为时间轴的时间筛选边界
- 评分系统的边界值（1-5分）
- 文件上传大小和类型限制

### 2. 压力测试
可以测试以下压力情况：
- 大量消息推送时的系统性能
- 高并发用户反馈提交时的响应时间
- 大量用户行为数据展示时的前端渲染性能
- 图片上传处理的并发性能

### 3. 用户体验测试
可以测试以下用户体验指标：
- 新手引导漫游系统的易用性
- 反馈表单的填写便捷性
- 用户行为时间轴的信息可读性
- 消息中心的通知清晰度
- 健康日报助手的内容相关性

## 部署说明

### 前端部署
```bash
# 进入前端目录
cd frontend/ms_frontend

# 安装依赖
npm install

# 开发环境运行
npm run serve

# 构建生产环境代码
npm run build
```

### 后端部署
```bash
# 进入后端目录
cd backend

# 安装依赖
pip install -r requirements.txt

# 创建数据库表
# 在MySQL中执行schema_additions.sql

# 运行后端服务
python app.py
```

## 注意事项

- 本系统需要与其他子系统集成才能完整运行，如用户认证系统、预约挂号系统等
- 默认的数据库连接配置需要根据实际环境进行修改
- 消息推送功能需要配置有效的邮件服务器和短信服务商账号
- 文件上传目录需要适当的权限设置
