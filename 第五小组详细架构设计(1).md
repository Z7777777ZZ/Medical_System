## 概述

用户服务子系统将作为现有互联网医疗系统的扩展模块，提供用户体验增强功能，包括新手引导、用户反馈、消息推送、用户行为跟踪及健康日报

**新手引导漫游系统**

**用户反馈系统**

**系统消息推送**

**用户行为时间轴**

**健康日报助手**

## 数据库额外设计

在原有数据的基础上，添加以下表结构

```SQL
-- 新手引导内容表(内容由管理员配置)
CREATE TABLE guide_contents (
    guide_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    guide_type ENUM('system_usage', 'appointment', 'problem_solving') NOT NULL,
    title VARCHAR(100) NOT NULL,
    content TEXT NOT NULL,
    image_url VARCHAR(255),
    target_element VARCHAR(100),
    position VARCHAR(50),
    order_index INT NOT NULL,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 用户引导进度表
CREATE TABLE guide_progress (
    progress_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    patient_id BIGINT NOT NULL,
    guide_type ENUM('system_usage', 'appointment', 'problem_solving') NOT NULL,
    completed BOOLEAN DEFAULT FALSE,
    last_position VARCHAR(100),
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (patient_id) REFERENCES patients(patient_id)
);

-- 用户反馈表
CREATE TABLE feedbacks (
    feedback_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    patient_id BIGINT NOT NULL,
    doctor_id BIGINT,
    appointment_id BIGINT,
    feedback_type ENUM('treatment_experience', 'recovery_progress') NOT NULL,
    rating INT NOT NULL CHECK (rating BETWEEN 1 AND 5),
    content TEXT,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (patient_id) REFERENCES patients(patient_id),
    FOREIGN KEY (doctor_id) REFERENCES doctors(doctor_id),
    FOREIGN KEY (appointment_id) REFERENCES appointments(appointment_id)
);

-- 通知表
CREATE TABLE notifications (
    notification_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    patient_id BIGINT NOT NULL,
    type ENUM('appointment_reminder', 'recheck_reminder', 'feedback_request', 'health_tip') NOT NULL,
    title VARCHAR(100) NOT NULL,
    content TEXT NOT NULL,
    related_id BIGINT,
    is_read BOOLEAN DEFAULT FALSE,
    deliver_email BOOLEAN DEFAULT TRUE,
    deliver_sms BOOLEAN DEFAULT FALSE,
    email_sent BOOLEAN DEFAULT FALSE,
    sms_sent BOOLEAN DEFAULT FALSE,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    send_at DATETIME NOT NULL,
    FOREIGN KEY (patient_id) REFERENCES patients(patient_id)
);

-- 通知偏好设置表
CREATE TABLE notification_preferences (
    preference_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    patient_id BIGINT NOT NULL UNIQUE,
    email_enabled BOOLEAN DEFAULT TRUE,
    sms_enabled BOOLEAN DEFAULT FALSE,
    appointment_reminder_days_before INT DEFAULT 1,
    recheck_reminder_days_before INT DEFAULT 3,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (patient_id) REFERENCES patients(patient_id)
);

-- 用户行为记录表
CREATE TABLE user_activities (
    activity_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    patient_id BIGINT NOT NULL,
    activity_type VARCHAR(50) NOT NULL,
    description TEXT NOT NULL,
    related_id BIGINT,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (patient_id) REFERENCES patients(patient_id)
);

-- 健康贴士表
CREATE TABLE health_tips (
    tip_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(100) NOT NULL,
    content TEXT NOT NULL,
    category VARCHAR(50) NOT NULL,
    has_ad BOOLEAN DEFAULT FALSE,
    ad_content TEXT,
    ad_link VARCHAR(255),
    publish_date DATE NOT NULL,
    expiry_date DATE,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    active BOOLEAN DEFAULT TRUE
);

-- 用户健康日报订阅表
CREATE TABLE health_tip_subscriptions (
    subscription_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    patient_id BIGINT NOT NULL,
    frequency ENUM('daily', 'weekly', 'monthly') NOT NULL DEFAULT 'weekly',
    categories VARCHAR(255),
    active BOOLEAN DEFAULT TRUE,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (patient_id) REFERENCES patients(patient_id)
);
```

## 子系统API设计

> 根据主系统的API设计，所有API相应格式为

```json
{
  "status": "success" | "error",
  "message": "描述性消息",
  "data": { /* 具体数据对象 */ }
}
```

### 4.1 新手引导模块 API

#### 4.1.1 获取引导内容

- 方法：GET
- 路径：/api/guides/{guide_type}
- 描述：获取指定类型的引导内容
- 参数：
  - `guide_type`: 引导类型 (system_usage, appointment, problem_solving)
- 响应：

```json
{
  "status": "success",
  "message": "获取成功",
  "data": {
    "guides": [
      {
        "guide_id": 1,
        "title": "如何注册和登录",
        "content": "点击右上角的'注册'按钮开始...",
        "image_url": "/assets/guides/register.png",
        "target_element": "#register-btn",
        "position": "bottom",
        "order_index": 1
      },
      // 更多步骤...
    ]
  }
}
```

#### 4.1.2 更新引导进度

- 方法：POST
- 路径：/api/guides/progress
- 描述：更新用户的引导完成进度
- 请求体：

```json
{
  "guide_type": "system_usage",
  "completed": false,
  "last_position": "step_3"
}
```

- 响应：

```json
{
  "status": "success",
  "message": "引导进度已更新",
  "data": null
}
```

### 4.2 用户反馈模块 API

#### 4.2.1 提交反馈

- 方法：POST
- 路径：/api/feedbacks
- 描述：提交就诊体验或恢复情况反馈
- 请求体：

```json
{
  "doctor_id": 123,
  "appointment_id": 456,
  "feedback_type": "treatment_experience",
  "rating": 5,
  "content": "医生态度很好，解释很详细"
}
```

- 响应：

```json
{
  "status": "success",
  "message": "反馈提交成功",
  "data": {
    "feedback_id": 789
  }
}
```

#### 4.2.2 获取用户反馈历史

- 方法：GET
- 路径：/api/feedbacks
- 描述：获取用户的反馈历史
- 参数：
  - `page`: 页码 (默认1)
  - `per_page`: 每页数量 (默认10)
- 响应：

```json
{
  "status": "success",
  "message": "获取成功",
  "data": {
    "total": 5,
    "page": 1,
    "per_page": 10,
    "feedbacks": [
      {
        "feedback_id": 789,
        "doctor_name": "张医生",
        "feedback_type": "treatment_experience",
        "rating": 5,
        "content": "医生态度很好，解释很详细",
        "created_at": "2025-04-20T15:30:45"
      },
      // 更多反馈...
    ]
  }
}
```

### 4.3 消息推送模块 API

#### 4.3.1 获取用户通知

- 方法：GET
- 路径：/api/notifications
- 描述：获取用户的通知列表
- 参数：
  - `page`: 页码 (默认1)
  - `per_page`: 每页数量 (默认10)
  - `type`: 通知类型 (可选)
  - `is_read`: 是否已读 (可选)
- 响应：

```json
{
  "status": "success",
  "message": "获取成功",
  "data": {
    "total": 15,
    "unread_count": 3,
    "page": 1,
    "per_page": 10,
    "notifications": [
      {
        "notification_id": 123,
        "type": "appointment_reminder",
        "title": "预约提醒",
        "content": "您明天上午10:00有一个与张医生的预约",
        "is_read": false,
        "created_at": "2025-04-19T09:00:00"
      },
      // 更多通知...
    ]
  }
}
```

#### 4.3.2 标记通知为已读

- 方法：PUT
- 路径：/api/notifications/{notification_id}/read
- 描述：将通知标记为已读
- 响应：

```json
{
  "status": "success",
  "message": "通知已标记为已读",
  "data": null
}
```

#### 4.3.3 更新通知推送偏好

- 方法：PUT
- 路径：/api/notifications/preferences
- 描述：更新用户通知偏好设置
- 请求体：

```json
{
  "email_enabled": true,
  "sms_enabled": true,
  "appointment_reminder_days_before": 2,
  "recheck_reminder_days_before": 5
}
```

- 响应：

```json
{
  "status": "success",
  "message": "通知偏好已更新",
  "data": null
}
```
